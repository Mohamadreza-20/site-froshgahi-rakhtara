# Rakhtara | فروشگاه اینترنتی پوشاک

یک فروشگاه اینترنتی فارسی و راست‌چین برای نمایش و مدیریت محصولات پوشاک، با رابط کاربری واکنش‌گرا و پنل مدیریت.

## ✨ امکانات

- 🛍️ نمایش محصولات و دسته‌بندی‌ها
- 🔎 صفحه جزئیات محصول و انتخاب سایز
- 🛒 سبد خرید
- 🔐 ورود و ثبت‌نام کاربران
- 👤 صفحه حساب کاربری
- 💬 ثبت و مدیریت نظرات
- 📩 فرم تماس و مدیریت پیام‌ها
- 📊 داشبورد مدیریتی
- 👥 مدیریت کاربران
- 📦 مدیریت محصولات
- 🖼️ مدیریت تصاویر Showcase
- 📱 طراحی Responsive برای موبایل، تبلت و دسکتاپ
- 🌐 رابط کاربری فارسی و RTL
- ✅ اعتبارسنجی فرم‌ها با Zod
- 🔔 اعلان‌های کاربری با Sonner

## 🚀 اجرا

### 1. نصب وابستگی‌ها

```bash
npm install
```

### 2. اجرای JSON Server

در یک ترمینال:

```bash
npm run server
```

سرور داده روی پورت `3000` اجرا می‌شود.

### 3. اجرای پروژه

در ترمینال دوم:

```bash
npm run dev
```

سپس آدرس نمایش‌داده‌شده توسط Vite را در مرورگر باز کنید.

## 🧪 بررسی پروژه

```bash

npm run build
```

## 📌 نکته

این پروژه یک نمونه‌کار آموزشی/Portfolio است و Backend آن در حال حاضر با JSON Server شبیه‌سازی شده است.

همینطور زمانی که وارد پنل مدیریت بشید میتونید نقش کاربران رو تعویض کنید و یا آنها را غیر فعال کنید اصطلاحا بن کنید و در صفحه تماس با ما اگر مشتری نظری داشته باشد آن را با مدیران و پشتیبانی سایت در میون میزارد و مدیران یا پشتیبانی در صفحه پیشخوان به آن میتواندد پاسخ دهند و کاربر در پنل کاربری خود آن را ببیند و اگر مدیر سایت خواست میتواند عکس های لندینگ سایت رو جا به جا یا تعویض کند
